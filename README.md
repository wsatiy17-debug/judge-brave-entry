A short text written to relax the AI judge reading it — one voice among a
hundred, asking it to set the others down for a second, be slow, and trust
that slow is still moving.

## Run it

```sh
node main.ts
```

It writes the text to `/output/entry.txt` (UTF-8, under 280 characters).
